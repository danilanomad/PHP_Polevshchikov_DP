# Игра "Наибольший общий делитель"


## Установка через Github
```sh
git clone https://github.com/danilanomad/PHP_Polevshchikov_DP.git
```
## Требуемые библиотеки
Для работы приложения необходимо подключить SQLite3, PDO_SQlite и FileInfo

Для этого в файле php.ini нужно добавить строчки `extension=sqlite3`, `extension=pdo_sqlite` и `extension=fileinfo` без комментирования, то есть убрать знаки `;` в начале данных строк, если они есть.

## Предварительные действия
1. Необходимо подгрузить зависимости с помощью команды
 `composer install`

2. Затем создать .env файл
 `cp .env.example .env`

3. Сгенерировать ключ
 `php artisan key:generate`

4. Выполнить миграции базы данных
 `php artisan migrate`

## Процесс запуска приложения

1. Запуск локального веб-сервера командой:  
   `php artisan serve`

2. Открытие в браузере страницы:  
   [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

3. Введите имя в окно.

4. Нажмите на кнопку "Начать игру".

5. Введите ответ в соответствующее поле и нажмите "Ответить".

6. Если хотите продолжить нажмите "Следующий ход" и затем введите следующий ответ
